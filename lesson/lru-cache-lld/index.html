LLD: LRU Cache

Hash map + doubly linked list with capacity eviction.

30 minintermediate#cache#lru

Design

O(1) get/put with capacity. Map key → node; list maintains recency (head=MRU, tail=LRU). On get: move to head. On put: update/move or insert; if over capacity, evict tail. Add mutex for concurrent use.

LRU sketchgo
type node struct {
	key, val   int
	prev, next *node
}

type LRUCache struct {
	cap        int
	items      map[int]*node
	head, tail *node
}

func Constructor(capacity int) LRUCache {
	h, t := &node{}, &node{}
	h.next, t.prev = t, h
	return LRUCache{cap: capacity, items: map[int]*node{}, head: h, tail: t}
}

func (c *LRUCache) Get(key int) int {
	n, ok := c.items[key]
	if !ok {
		return -1
	}
	c.moveToHead(n)
	return n.val
}

Time

O(1) get/put average

Space

O(capacity)
