Messaging & Event-Driven Design

Queues vs logs, delivery semantics, and outbox.

35 minadvanced#messaging#events

Semantics

At-most-once, at-least-once, exactly-once (usually effective exactly-once via idempotency). Queues (SQS/Rabbit) for task distribution; logs (Kafka) for replayable event streams. Consumer groups, DLQs, ordering keys, and backpressure matter.

Transactional outbox

Write business row + outbox row in one DB transaction; a publisher relays outbox to the broker. Avoids dual-write races between DB and queue.

Go service checklist

  1. 1.Idempotent handlers (dedupe keys)
  2. 2.Bounded worker pools
  3. 3.Context deadlines on processing
  4. 4.Metrics: lag, retries, DLQ depth
